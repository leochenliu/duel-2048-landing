how it works

One stream. Two players. Zero coordination.

Tiles spawn from the same shared event log. Each side sees the same tiles in the same positions at the same time. After that, you and the Agent are on your own.

  1. 1

    Share an event stream

    Every tile value, position, and timing is determined by a seed at game start. Both boards draw from the same stream — never the other way around.

  2. 2

    Play your side

    You move the left column with arrow keys. Swipe, plan, second-guess — your usual 2048 muscle memory, now under observation.

  3. 3

    Watch the Agent play

    The right column is driven by a skill you choose — heuristic, search-based, or LLM-driven. The Agent thinks out loud in the event log.

  4. 4

    Compare the divergence

    Scroll the shared event table. Every row shows the same tile and two different moves. Patterns emerge within 30 seconds.

five sync modes

Pick how coupled you want the duel.

Duel 2048 isn't one game — it's five. Same event stream, different rules of comparison.

Strict Sync

values + grid

Every tile value, spawn position, and merge result is identical on both sides. Compare pure policy.

Value-Only Sync

values only

Same tile values appear, but positions and merges are independent. A loose, chaotic comparison.

Independent

classic 2048 × 2

Two unrelated 2048 boards. Use this to benchmark an Agent's raw strength without coupling.

Lockstep

recommended

The Agent waits for you. Every row of the event table gets a human move and an Agent move. The cleanest comparison.

Free

AI runs first

The Agent plays at its own pace while you decide yours. Great for benchmarking without waiting on the human.

faq

Quick answers

What is Duel 2048?

A free browser puzzle game based on 2048, played side-by-side by you and an AI Agent on a shared event stream. Both sides get the same tiles; each side chooses its own moves.

How is the AI Agent playing?

The right column is driven by a configurable skill — typically a heuristic, search-based policy, or an LLM agent. You can swap policies and watch how the strategy changes.

What are the five sync modes?

Strict Sync (values + grid identical), Value-Only Sync (only tile values match), Independent (classic 2048 × 2), Lockstep (Agent waits for you — recommended for direct comparison), and Free (Agent plays at its own pace).

Is Duel 2048 free?

Yes. It runs entirely in your browser. No login, no accounts, no tracking beyond what's needed to serve the page.

Why is this different from watching AI play 2048?

Spectacle videos show what a model can do. Duel 2048 shows how a model's choices diverge from yours on the same problem — the comparison is the experience.

Can I share a replay?

Every game has a deterministic seed and an id in the URL. Send the link to anyone and they'll see the exact same match.

Does it work on mobile?

Yes. Swipe to play. The dual-board layout collapses into a tabbed view below 768 px.
